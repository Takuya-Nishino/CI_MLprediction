# CI_MLprediction

Reproducibility code for:

**Landmark-Based Prediction of No Direct Home Discharge and Prolonged Hospitalization After Acute Stroke: A Retrospective Cohort Study with Temporal Evaluation**

This repository contains the analysis code used for the Day 3 and Day 7 landmark prediction study. Patient-level clinical data are not included because of institutional, ethical, and privacy restrictions.

## Analysis workflow

Run the notebooks in the following order:

1. `01_main_analysis.ipynb`
   - constructs the Day 3 and Day 7 landmark risk sets
   - develops L2-penalized logistic regression and LightGBM models
   - performs chronological temporal evaluation
   - saves locked fitted-model bundles and primary performance results

2. `02_sensitivity_analysis.ipynb`
   - performs prespecified sensitivity analyses
   - performs the paired Day 3 versus Day 7 landmark comparison

3. `03_tables_figures.ipynb`
   - generates manuscript tables and publication figures from the locked results
   - does not refit the primary models

4. `04_shap_analysis.ipynb`
   - calculates LightGBM SHAP values from the locked primary-model bundle
   - generates Supplementary Figures S4 and S5

## Input data

The code expects an authorized local copy of the analysis dataset at:

```text
data/input.xlsx
```

Alternatively, edit `DATA_PATH` in the user-editable configuration block.

The source dataset is not distributed with this repository. The code retains the original source-variable names used in the institutional dataset so that the analytical definitions correspond directly to those used in the study.

## Output directory

Generated files are written under:

```text
outputs/
```

The `outputs/` directory is excluded from version control because it may contain fitted model objects, patient-level predictions, diagnostic files, and derived tables.

## Reproducibility

The manuscript analyses used:

- Python 3.11.11
- random seed: `20260902`
- 5-fold stratified cross-validation
- 100 Optuna trials for LightGBM tuning
- 1000 patient-level bootstrap resamples for confidence intervals
- a development-derived screening threshold targeting approximately 80% sensitivity

Package versions reported in the manuscript are listed in `requirements.txt`.

## Manuscript figure mapping

- Figure 2: ROC curves
- Figure 3: calibration plots
- Figure 4: Day 3 / Day 7 two-dimensional operational risk matrices using penalized logistic regression
- Supplementary Figure S1: precision-recall curves
- Supplementary Figure S2: decision curve analysis
- Supplementary Figure S3: Day 3 / Day 7 operational risk matrices using LightGBM
- Supplementary Figures S4-S5: LightGBM SHAP summaries

Figure 1 is an editable study-flow diagram and is not generated by these notebooks.

## Data privacy

Do **not** commit:

- patient-level source data;
- patient identifiers or exported patient-level prediction files;
- fitted model bundles generated from the clinical data;
- local output directories.

Notebook execution outputs and local machine paths were removed from the public-release versions committed here.

## Code availability

The repository provides the analytical workflow used for model development, temporal evaluation, paired landmark analyses, sensitivity analyses, table/figure generation, and model interpretation. Reproduction of numerical results requires authorized access to the underlying institutional dataset.
